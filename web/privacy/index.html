GIF Crop Lab

Privacy

Updated November 25, 2026.

Your files stay on your device

GIF Crop Lab reads and processes the file you select in your browser. The tools do not upload your GIF or video, filename, editing settings, or generated file to a server. Previews and downloads use temporary browser URLs.

Website requests

Your browser requests the website's HTML, scripts, styles, and icons from its hosting provider. Normal website requests can include your IP address, browser information, and the requested URL. Browser-local image processing does not prevent the hosting provider from handling this connection information.

Cookies and analytics

GIF Crop Lab uses Cloudflare Web Analytics to measure page views, referral sources, and page load performance. Cloudflare Web Analytics does not use cookies. GIF Crop Lab also uses Microsoft Clarity for website usage analytics. Learn more about Microsoft Clarity. File processing takes place in your browser. Learn more about Cloudflare Web Analytics.

Closing the page and saving files

Replacing a file or closing the page releases the application's temporary references. Your browser and operating system manage memory and caching; this is not a guarantee of secure deletion. Files you download remain wherever you save them.

Privacy questions

For privacy questions, contact ciel@gifcroplab.com.

Support

You can find the project and report problems on GitHub. GitHub is an external service with its own privacy practices. Keep private images on your device. Start with your browser version and the error message; share a sample GIF only if you choose to do so and have permission to share it.
